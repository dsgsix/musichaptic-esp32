# MusicHaptic 2.5.0

- Conserva la frecuencia de cada nota al reproducir pistas.
- Utiliza el protocolo v4 con intensidad global aplicada después de GAIN.
- Las pruebas izquierda/derecha/ambos respetan el nivel seleccionado.
- Permite cambiar la intensidad durante la reproducción.
- Genera audio mono DO4–SI4 mediante AudioTrack.
- Migra la preferencia de reproducción de audio con brazalete.

Consulta [LEEME_PRIMERO.md](LEEME_PRIMERO.md) y [VERIFICACION.md](VERIFICACION.md) para instalación y comprobaciones.
